# Stacksmith Homebrew tap

Formulae for [Stacksmith](https://getstacksmith.app/) tools.

```sh
brew install getstacksmith/tap/stacksmith
```

`stacksmith` runs and inspects local development stacks defined in
`.stacksmith.yml`. It needs an Apple silicon Mac running macOS 14 or later.

Formulae here are generated by the Stacksmith release pipeline; please do not
edit them by hand. Report problems at
[getstacksmith/stacksmith-releases](https://github.com/getstacksmith/stacksmith-releases/issues).
